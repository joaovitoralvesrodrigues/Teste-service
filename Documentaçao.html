Como funcionam as tags <audio> e <video>?

Introduzidas no HTML5, as tags <audio> e <video> vieram para substituir a necessidade de plugins externos (como o antigo Adobe Flash). Elas permitem a renderização nativa de arquivos de mídia diretamente no navegador, melhorando a performance e a acessibilidade.

Dentro dessas tags, costumamos usar a tag filha <source> para indicar o caminho do arquivo e o tipo de formato (MIME type). Isso permite oferecer formatos alternativos caso o navegador do usuário não suporte o principal.

Estrutura Básica de Exemplo:

<video controls width="320" height="240">
  <source src="filme.mp4" type="video/mp4">
  <source src="filme.ogg" type="video/ogg">
  Seu navegador não suporta este vídeo.
</video>

Tabela de Atributos e Suas Funções

Abaixo estão listados os principais atributos utilizados para controlar o comportamento e a aparência das mídias digitais no HTML:

Atributo Aplica-se a Descrição / Para que serve
src Ambos Especifica a URL (caminho) do arquivo de áudio ou vídeo que será reproduzido.
controls Ambos Exibe os controles padrão do navegador (botão Play/Pause, barra de volume, tempo decorrido, tela cheia). Sem ele, a mídia fica invisível ou inacessível visualmente (a menos que controlada por Javascript).
autoplay Ambos Faz com que o arquivo comece a rodar automaticamente assim que a página carregar. *Nota: A maioria dos navegadores bloqueia som automático; se usado em vídeo, costuma exigir o atributo muted junto.
loop Ambos Faz com que a mídia recomece do início automaticamente assim que terminar, em um ciclo infinito.
muted Ambos Define que o áudio começará silenciado por padrão.
preload Ambos Informa ao navegador o que carregar previamente na página. Valores: none (não carrega nada), metadata (carrega só duração/tamanho) ou auto (carrega o arquivo inteiro antes do play).
poster Vídeo Especifica o caminho de uma imagem a ser exibida como "capa" do vídeo enquanto ele não é reproduzido ou baixado.
width / height Vídeo Define a largura e a altura da área de exibição do vídeo em pixels.
