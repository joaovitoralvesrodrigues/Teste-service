Objetivo da Página

Este site foi desenvolvido com o propósito de apresentar a coleção exclusiva de quadros disponíveis para venda na exposição virtual "Cores do Amanhã". Explicação dos Posicionamentos CSS Utilizados

Para estruturar esta página, aplicamos os conceitos fundamentais de posicionamento web. Veja abaixo como e por que cada um foi utilizado:

1. position: fixed; (Menu Superior)

Como foi usado: Aplicado na tag <header> para travá-la no topo da tela (top: 0; left: 0;).

Objetivo prático: Garante que o menu de navegação permaneça sempre visível e acessível para o usuário, independentemente de quanta rolagem ele faça para baixo na página.

2. position: sticky; (Faixa Amarela de Aviso)

Como foi usado: Aplicado na div de anúncio de frete grátis com um deslocamento de top: 70px;.

Objetivo prático: Ela age de forma normal (estática) inicialmente, mas assim que o usuário rola a página e ela atinge a base do menu fixo (70px), ela passa a se comportar como "fixa" temporariamente, acompanhando a rolagem do usuário para reter sua atenção.

3. position: static; (Bloco de Objetivo do Site)

Como foi usado: É o comportamento padrão de layout. Foi explicitado na seção .site-objective.

Objetivo prático: Seguir o fluxo natural de leitura e renderização do navegador. O elemento é construído empilhado de forma padrão, respeitando as margens normais da página sem nenhuma flutuação especial.

4. position: relative; (Cartão/Contêiner da Obra)

Como foi usado: Aplicado na classe .art-card que envelopa cada quadro.

Objetivo prático: Modificar o elemento para que ele funcione como um "ponto de referência espacial". Sem isso, qualquer elemento filho absoluto que estivesse dentro dele usaria a tela inteira (o corpo da página) como referência de posicionamento.

5. position: absolute; (Etiquetas "Destaque" / "Disponível")

Como foi usado: Aplicado na classe .art-badge, configurando top: 15px; right: 15px;.

Objetivo prático: Retirar a etiqueta do fluxo normal do texto e fazê-la flutuar de forma precisa no canto superior direito de cada imagem. Como o pai dela é relative, ela fica perfeitamente presa às bordas internas do respectivo cartão.
